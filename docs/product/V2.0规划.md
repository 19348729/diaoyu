三大阶段业务动线（三步握手流）新版的业务逻辑不再强求小程序长驻后台，而是完全顺应钓鱼佬一天的操作动线，只在关键节点引发 3次精密握手：阶段一：出钓开局配置（第一次握手）用户目标：做好出发准备，为 AI 专家注入“战术上下文”。业务动作：用户在岸边架好竿，小程序秒连 ESP32，下发对时指令并确认硬件在线。用户在界面上通过极简的粗颗粒大标签勾选今天想钓的目标鱼（如土鲮）、预设钓法（如底钓）及今日饵料（如香腥）。点击“开始作钓”后手机放回口袋。设备自治：硬件终端沉入水底后，断开蓝牙，每 10-15 分钟由 RTC 定时器唤醒，静默采集 DS18B20（三层水温）和 BMP280（绝对气压），落盘至本地 RingBuffer，随后切回深睡眠（Deep-sleep）。阶段二：鱼情异常卡壳（第二次握手 - 产品的灵魂核心）用户目标：钓了 1 小时完全没口、或者全是小鱼截口乱口，心烦意乱想要寻求技术纠偏。业务动作：钓鱼佬拿出手机解锁开屏（此时蓝牙重连）。物理回溯（1秒完成）：硬件在 1 秒内将过去数小时缓存在本地的温压时序数组全量 Dump 同步给手机。视界主观补偿（拍砖触控）：钓鱼佬用手指关节或手肘随便一拍，勾选水面主观症状（如：[√] 有细密地星跑泡但不咬钩、[√] 无杂鱼截口）。AI 开具战术处方：Django 进行本地指标求导，联合大模型动态弹出标准 JSON 排版的“神医处方卡片”，明确指出停口原因（如：表底温差大产生温跃层、气压阴跌导致底层缺氧）并直接给出 2 条极具实操性的改钓法建议（如：立刻推漂 30cm 钓离底、饵料加轻粉拦截行程）。阶段三：收竿渔获复盘（第三次握手 - 商业裂变刚需）用户目标：钓完鱼搬装备上车，准备发朋友圈或者钓友群“装杯”炫耀。业务动作：点击“结束作钓”，极简勾选今日渔获等级（空军 / 惨淡 / 稳赚 / 爆护）。裂变海报：Django 后端拉取全天完整水文曲线，结合用户等级，利用 Canvas 动态合成一张充满钓鱼圈黑话和极强荣誉感的朋友圈长图海报（如：“明哥今日正面迎战2.5hPa暴跌气压，通过AI起浮预警一键切半水，极限拉起5斤大罗非，击败全网95%钓友！”），牢牢抓死垂钓圈的炫耀心理，达成无成本社交裂变。🛠️ 三、 全栈技术分工：传统算法与 LLM 的边界划分为了在 wild 实战中保障零延迟、低 Token 成本且绝对没有幻觉，我们在代码逻辑上将做如下精密分工：[微信小程序 (前台触控)] ── 负责极简UI交互、主观特征收集与蓝牙数据批量 Dump

边缘硬件与小程序（GATT 协议重构）：硬件只管依靠 ring_buffer.py 存数据，蓝牙通道由原来的“Notify 监听器模式”重构为“REQ-ACK 批量快闪同步模式”。Django 后端领域层（干脏活、做硬性过滤）：利用 analyzers.py 自主算出 2 小时气压变率 $\Delta P$、表底水温差值，并通过《智能钓鱼数据模型设计报告》里的广东鱼群生理特性常数矩阵，打上硬规则标签。绝不让大模型在云端做任何数学计算。大模型（当好翻译官和老师傅）：System Prompt 严格限定角色为“30年华南水域硬核老钓手”，将后端算好的硬核物理状态与用户勾选的表象进行高智商交融，只负责生成排版干净的文字处方字典。📅 四、 下一步交付状态（Deliverables）这个改造目标的终点，将直接交付给你：一个超级省电的感知盒子：丢在水里连不连手机都无所谓。一个干净清爽的小程序界面：没有密密麻麻看不懂的实时仪表盘和复杂折线，只有出钓配置卡片、“AI 鱼情救场”大按钮和最后的战报生成器。一个极度硬核的 Django 算法大脑：它能把气压变率、溶解氧、逆温层算得极准，并能够驱动云端 AI 像邓刚老师傅一样坐在钓鱼佬旁边出谋划策。
