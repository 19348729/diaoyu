# 02 快速开始

## 2.1 环境要求

- Python **3.9+**（推荐 3.10/3.11）
- pip 21+
- 操作系统：Linux / macOS / Windows
- 可选：MySQL 5.7+ / 8.0（生产环境）

## 2.2 安装依赖

```bash
pip install -r requirements.txt
```

依赖清单（[`requirements.txt`](file:///d:/diaoyu/diaoyu/requirements.txt)）：

```text
fastapi>=0.100.0
uvicorn[standard]>=0.23.0
gunicorn>=21.2.0
dashscope>=1.14.0
sqlalchemy>=2.0.0
```

> 注：`httpx`、`pydantic`、`python-dotenv`、`pymysql` 由上述包间接拉入或在运行时按需安装。若 MySQL 部署需手工安装 `pymysql` 或 `mysqlclient`。

## 2.3 环境变量

后端通过 [`python-dotenv`](file:///d:/diaoyu/diaoyu/infrastructure/database.py) 加载根目录的 `.env` 文件。常用变量：

| 变量 | 必填 | 说明 |
|------|------|------|
| `DATABASE_URL` | 否 | 数据库连接串。未设置时回退到 `sqlite:///diaoyu.db` |
| `QWEATHER_API_KEY` | 否 | 和风天气 Key。代码内有默认 fallback Key |
| `DASHSCOPE_API_KEY` | 否 | 通义千问 Key。缺失时 `/api/v2/rescue` 走兜底文案 |
| `WX_APPID` / `WX_APP_SECRET` | 登录用 | 微信小程序登录所需，见 [`server.py`](file:///d:/diaoyu/diaoyu/server.py) |

`.env` 示例：

```ini
DATABASE_URL=mysql+pymysql://root:123456@127.0.0.1:3306/diaoyu_db?charset=utf8mb4
QWEATHER_API_KEY=your_qweather_key
DASHSCOPE_API_KEY=sk-xxxxxxxxxxxx
WX_APPID=wx1234567890
WX_APP_SECRET=your_wx_secret
```

完整集成说明见 [09-外部集成与配置](./09-外部集成与配置.md)。

## 2.4 数据库初始化

应用启动时会自动执行 `Base.metadata.create_all(bind=engine)`（[`server.py` 行 32-33](file:///d:/diaoyu/diaoyu/server.py)），自动建立缺失的表。

老版本 SQLite 升级到 V2 协议，需要补充 `t_water` / `t_air` 字段：

```bash
python migrate_v2.py
```

参见 [06-基础设施层](./06-基础设施层.md#数据迁移)。

## 2.5 本地启动

```bash
python server.py
```

服务监听 `0.0.0.0:8000`，开启 reload。访问入口：

- 健康检查：<http://127.0.0.1:8000/health>
- Swagger 交互文档：<http://127.0.0.1:8000/docs>
- ReDoc：<http://127.0.0.1:8000/redoc>

## 2.6 命令行算法演示

无需启动 HTTP 服务，可直接跑通预测算法：

```bash
python main.py --fish 鲫鱼 --mode series
```

参数：

- `--fish`：鱼种，可选值见 `FISH_PROFILES` 的 8 种鱼（鲫鱼 / 鲤鱼 / 罗非鱼 / 大口黑鲈 / 土鲮 / 草鱼 / 鲢鳙 / 塘鲺 / 翘嘴）。
- `--mode`：`snapshot`（单帧）/ `series`（时序，默认）/ `weather`（纯天气）。

源码：[`main.py`](file:///d:/diaoyu/diaoyu/main.py) 用 `_build_mock_series` 构造 30 分钟模拟数据。
