## 6.1 数据库连接 `database.py`

源码：[`database.py`](file:///d:/diaoyu/diaoyu/infrastructure/database.py)（50 行）。

### 双引擎自适应

```python
SQLALCHEMY_DATABASE_URL = os.getenv("DATABASE_URL")
if not SQLALCHEMY_DATABASE_URL:
    SQLALCHEMY_DATABASE_URL = f"sqlite:///{BASE_DIR}/diaoyu.db"
```

- 未配置 `DATABASE_URL` → 落到本地 `diaoyu.db`（SQLite）
- 配置后 → 自动切换到 MySQL / PostgreSQL 等

### SQLite 必备配置

```python
engine = create_engine(URL, connect_args={"check_same_thread": False})
```

`check_same_thread=False` 是 FastAPI 多线程异步必备。

### MySQL 池化

```python
engine = create_engine(URL,
    pool_size=10,        # 连接池
    max_overflow=20,     # 最大超量
    pool_recycle=3600    # 防 MySQL 8 小时自动断开
)
```

### Session 工厂与依赖注入

```python
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)
Base = declarative_base()

def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

FastAPI 路由用 `Depends(get_db)` 拿到 `Session`，请求结束自动关闭。

## 6.3 数据迁移

### 自动建表

[`server.py` 行 32-33](file:///d:/diaoyu/diaoyu/server.py)：

```python
Base.metadata.create_all(bind=engine)
```

启动时自动创建缺失的表，**已存在的表不会被修改**。

### V2 字段迁移 `migrate_v2.py`

[`migrate_v2.py`](file:///d:/diaoyu/diaoyu/migrate_v2.py) 用于把 V1 的 SQLite 数据库升级到 V2 字段：

```python
ALTER TABLE sensor_records ADD COLUMN t_water FLOAT
ALTER TABLE sensor_records ADD COLUMN t_air   FLOAT
```

并捕获 `duplicate column name` 异常以保证幂等。结尾再调 `Base.metadata.create_all` 创建 V2 新增表（如 `fishing_sessions` / `public_*`）。

运行：

```bash
python migrate_v2.py
```

> **MySQL 用户**：脚本目前只对 SQLite 文件生效。MySQL 直接依赖应用启动时的 `create_all`，`ALTER TABLE` 需自行执行。

## 6.4 索引建议

`openid` 在所有用户表上已加 `index=True`。生产环境建议补充：

- `sensor_records (openid, timestamp DESC)` 复合索引：加速 `/api/sensor/records` 拉取
- `prediction_history (openid, created_at DESC)` 复合索引：加速 `/api/history/logs`
- `fishing_sessions (openid, created_at DESC)` 复合索引：加速 `/api/session/list`
