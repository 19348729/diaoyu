# 01 项目概述

## 1.1 定位

后端服务是「AI 钓鱼智能系统」的算法与数据中枢，向微信小程序、ESP32 硬件提供 HTTP API。核心职责包括：

1. **多因子鱼情预测**：基于传感器时序、实时天气、月相、风向湿度等多维信号，输出 0–100 的开口指数与战术建议。
2. **天气预报鱼情**：消费和风天气 24h 逐小时与 3 日预报，给出"几点出门最佳"。
3. **传感器数据持久化**：接收实时与批量上报的水温 / 气压数据。
4. **数字钓箱（装备库）**：鱼竿 / 主线 / 子线 / 浮漂 / 饵料的 CRUD 与 UGC 众包。
5. **V2 AI 救场**：调用通义千问，结合物理标签 + 主观症状生成战术处方，并根据《大师战术与配方百科全书》检索 Top-3 大师秘籍作为 RAG 参考。
6. **战报海报**：会话结束后基于统计结果生成炫耀海报数据。

## 1.2 技术选型

| 维度 | 选型 |
|------|------|
| Web 框架 | **FastAPI**（异步、内置 OpenAPI/Swagger） |
| ASGI 服务器 | **Uvicorn**（开发） / **Gunicorn + UvicornWorker**（生产） |
| ORM | **SQLAlchemy 2.0** |
| 数据库 | **SQLite**（默认本地） / **MySQL**（生产，通过 `DATABASE_URL`） |
| LLM | 阿里 **DashScope（通义千问 qwen-turbo / qwen-plus）** |
| HTTP 客户端 | **httpx**（异步） |
| 测试 | **pytest** |

依赖见 [`requirements.txt`](file:///d:/diaoyu/diaoyu/requirements.txt)：`fastapi >= 0.100`、`uvicorn[standard] >= 0.23`、`gunicorn >= 21.2`、`dashscope >= 1.14`、`sqlalchemy >= 2.0`。

## 1.3 分层结构

后端按 DDD 思想分层：

- **接入层**：[`server.py`](file:///d:/diaoyu/diaoyu/server.py) ── 仅负责 HTTP 协议解析、Pydantic 入出参、依赖注入；不写业务规则。
- **领域层**：[`domain/`](file:///d:/diaoyu/diaoyu/domain) ── 全部业务逻辑、算法、外部 API 客户端。
- **基础设施层**：[`infrastructure/`](file:///d:/diaoyu/diaoyu/infrastructure) ── 数据库连接 / 模型。
- **运维层**：[`deploy/`](file:///d:/diaoyu/diaoyu/deploy) + [`gunicorn.conf.py`](file:///d:/diaoyu/diaoyu/gunicorn.conf.py) ── systemd / Nginx / Gunicorn 配置。

详细依赖关系见 [03-系统架构](./03-系统架构.md)。

## 1.4 关键特性

### 渐进式置信度

预测置信度随采集时长平滑增长（对数增长模型，见 [`get_confidence`](file:///d:/diaoyu/diaoyu/domain/time_utils.py)）：

| 采集时长 | 阶段 | 置信度 | 启用特征 |
|---------|------|-------|---------|
| 0 s | `instant` | 30% | 仅最新单条快照 |
| ≥ 5 min | `brief` | ≈49% | + 气压趋势、溶氧估算 |
| ≥ 10 min | `standard` | ≈63% | + 温度趋势、温跃层 |
| ≥ 30 min | `full` | ≈83% | 全量深度分析 |

### 多因子加权

[`FishingPredictionService.predict_from_series`](file:///d:/diaoyu/diaoyu/domain/services.py) 至少融合 16 个修正项：水温基准、气压动态/绝对值/短期突变、溶氧、天气、时段、季节、温跃层、温度趋势/速率、月相、风向、湿度、三层水温空间、风力等级。

### 一票否决

气压 2h 跌幅 ≤ `pressure_crash_threshold`（默认 -3.0 hPa）触发 `RATING_VETO`，强制返回 `pressure_crash_score=5` 分。见 [`_calc_pressure_modifier`](file:///d:/diaoyu/diaoyu/domain/services.py)。

### V1/V2 协议兼容

`SensorDataIn` 同时接受 V1 三层水温（`t_bottom/t_mid/t_surface`）与 V2 单水温 + 气温（`t_water/t_air`）。后端在 [`predict`](file:///d:/diaoyu/diaoyu/server.py) 内通过 `_to_reading` 用热力学加权（系数 0.65）将 V2 单点降级映射成三层结构，使下游算法保持统一接口。

### 大师知识库 RAG

将《大师战术与配方百科全书》清洗为 322 条结构化秘籍（[`data/master_kb.jsonl`](file:///d:/diaoyu/diaoyu/data/master_kb.jsonl)），[`MasterKBRetriever`](file:///d:/diaoyu/diaoyu/domain/master_kb.py) 在调用 LLM 前按（鱼种 / 季节 / 水温 / 气压）多维评分召回 Top-3，注入 user prompt。详见 [10-大师知识库RAG](./10-大师知识库RAG.md)。
