# 05 领域层详解

[`domain/`](file:///d:/diaoyu/diaoyu/domain) 是后端业务核心，所有算法、外部 API、Prompt 模板均位于此。本文按"价值对象 → 工具 → 引擎 → 服务 → 集成"顺序梳理。

## 5.1 值对象 `value_objects.py`

不可变 `frozen=True` dataclass，遵循 DDD Value Object：自校验、无身份。

| 类 | 说明 |
|----|------|
| `HardwareData` | V1 单帧硬件快照（`t_water` / `p_local` / `delta_p`）；构造时校验范围 |
| `ApiData` | 云端气象数据（风速、海拔、`weather_trend`、风向、湿度、原始文本）；含枚举白名单校验 |
| `SensorReading` | 单条时序读数（三层水温 + 气压 + timestamp） |
| `SensorTimeSeries` | 时序集合，提供 `latest` / `earliest` / `duration_seconds` / `count` 属性 |
| `SessionContext` | 会话上下文（time_period / season / duration / report_stage） |
| `PredictionResult` | 出参；`bite_index` 强制 0–100 范围 |

源码：[`value_objects.py`](file:///d:/diaoyu/diaoyu/domain/value_objects.py)。

## 5.2 配置 `constants.py`

集中所有可调参数，便于后续接配置中心。

关键 Dataclass：

- `DissolvedOxygenConfig`：溶氧公式系数 `k`、`alpha`
- `FishSpeciesProfile`：鱼种适温、容忍区、各档基准分、`bait_by_season`、`fishing_method`
- `FISH_PROFILES`：内置 8 种鱼（鲫 / 鲤 / 罗非 / 大口黑鲈 / 土鲮 / 草鱼 / 鲢鳙 / 塘鲺 / 翘嘴）
- `BiteIndexConfig`：阈值与权重（`pressure_crash_threshold = -3.0`、`do_danger_line = 4.0`、`weather_bonus_map` 等）
- `TimePeriodConfig`：`morning(5-10) / noon(10-14) / afternoon(14-18) / evening(18-5)` 与各时段加分
- `SeasonConfig`：四季月份映射、`score_modifier`、`optimal_temp_shift`、文案
- `ProgressiveStageConfig`：阶段定义与启用特征
- `ThermoclineConfig` / `SolunarConfig` / `PressureAnalysisConfig` / `WindDirectionConfig` / `HumidityConfig` / `WindSpeedConfig` / `AirToWaterConfig` / `PressureAbsoluteConfig`

[`constants.py`](file:///d:/diaoyu/diaoyu/domain/constants.py) 共 600+ 行，所有调参从这里开始。

## 5.3 时间工具 `time_utils.py`

无状态函数，对外暴露：

| 函数 | 作用 |
|------|------|
| `get_time_period(ts)` | 根据时间戳判定时段 `morning/noon/afternoon/evening`（CST） |
| `get_season(ts)` | 判定季节 |
| `get_report_stage(duration)` | 判定 `instant/brief/standard/full` |
| `get_confidence(duration)` | 对数增长平滑置信度 30→95 |
| `get_stage_features(duration)` | 当前阶段启用的分析特征列表 |
| `build_session_context(readings)` | 从读数列表构造 `SessionContext` |

源码：[`time_utils.py`](file:///d:/diaoyu/diaoyu/domain/time_utils.py)。

## 5.4 时序分析器 `analyzers.py`

`TimeSeriesAnalyzer` 全部为 `@staticmethod`，无状态：

| 方法 | 用途 |
|------|------|
| `calc_pressure_delta(readings, window=7200)` | 2h 气压变化率 |
| `calc_pressure_trend_detail` | 气压趋势详细分析（`crash/dropping/rising/stable`） |
| `calc_pressure_multi_window` | 多窗口气压抖动 |
| `calc_temp_trend(readings, field)` | 线性回归判趋势 |
| `calc_temp_trend_detail` | 温度速率（含快速变化检测） |
| `calc_thermocline_index` | 温跃层强度指数 |
| `analyze_thermal_profile` | 三层水温空间分布与分层状态 |
| `calc_averages` | 字段均值 |
| `select_reference_temp(reading, layer)` | 按鱼种水层挑参考水温 |

源码：[`analyzers.py`](file:///d:/diaoyu/diaoyu/domain/analyzers.py)。

## 5.5 战术标签 `tags.py`

`TacticalTag(str, Enum)` 直接继承 `str`，可直接 JSON 序列化。覆盖：

- 状态：`STATUS_TEMP_OPTIMAL`、`STATUS_PRESSURE_CRASH`、`STATUS_DO_DANGER` …
- 阶段：`STAGE_INSTANT/BRIEF/STANDARD/FULL/WEATHER_ONLY`
- 评级：`RATING_EXCELLENT/GOOD/FAIR/POOR/VETO`
- 时段 / 季节 / 趋势 / 风向 / 风力 / 湿度 / 温跃层

源码：[`tags.py`](file:///d:/diaoyu/diaoyu/domain/tags.py)。

## 5.6 月相算法 `solunar.py`

纯天文计算，无外部依赖：

- `calc_moon_phase(ts) → (phase_name, age)`
- `calc_moon_illumination(ts) → 0~100`
- `is_solunar_peak_day(ts) → bool`
- `calc_solunar_rating(ts) → dict`：综合 phase / illumination / peak

被 `services.py` / `forecast.py` 调用以累加月相修正分。源码：[`solunar.py`](file:///d:/diaoyu/diaoyu/domain/solunar.py)。

## 5.7 物理引擎 `engine.py`

`FishingEngine.evaluate(series) → {tags, metrics}`：

- `metrics["delta_p_2h"]`：2h 气压变化
- `metrics["thermocline"]` / `mixing_state`：分层状态
- `metrics["t_water_avg"]` / `metrics["p_local_avg"]`
- `tags`：物理客观标签（不含主观情绪）

设计意图：把"数学"留给 Python，把"语言"留给 LLM。`/api/v2/rescue` 用它做诊断输入。源码：[`engine.py`](file:///d:/diaoyu/diaoyu/domain/engine.py)。

## 5.8 核心服务 `services.py`

[`FishingPredictionService`](file:///d:/diaoyu/diaoyu/domain/services.py) 是后端中枢，1400+ 行。三个公开入口：

### `predict(hardware, api)`
向后兼容的单帧快照预测。流水：基准分 → 气压加权（一票否决）→ 溶氧加权 → 天气加权 → 评级。

### `predict_from_series(series, api, session=None, user_inventory=None)` ⭐ 主接口
完整时序预测。内部 19 步流水（[`services.py` 行 202-419](file:///d:/diaoyu/diaoyu/domain/services.py)）覆盖 16 个修正项 + 战术建议生成。详见 [03-系统架构 §3.3](./03-系统架构.md#33-核心评分流水线)。

### `predict_weather_only(api, air_temp, lat=0, lng=0, hourly_forecast=None, user_inventory=None)`
纯天气模式，置信度固定 30%。用 `AirToWaterConfig.estimate_water_temp` 把气温折算为水温。

### 关键私有方法

| 方法 | 用途 |
|------|------|
| `_calculate_do_from_values` | 虚拟溶解氧（Benson & Krause 查表 + 气压 + 风力修正） |
| `_calc_temp_base_score` | 水温基准分 |
| `_calc_pressure_modifier` | 气压加权 + 一票否决 |
| `_calc_do_modifier` | 溶氧加权 |
| `_calc_thermocline_modifier` | 温跃层 |
| `_calc_time_period_modifier` / `_calc_season_modifier` | 时段 / 季节 |
| `_calc_solunar_modifier` | 月相 |
| `_calc_wind_direction_modifier` | 风向 × 季节交叉 |
| `_calc_humidity_modifier` / `_calc_wind_speed_modifier` | 湿度 / 风力 |
| `_calc_thermal_profile_modifier` | 三层水温空间分析 |
| `_calc_pressure_absolute_modifier` | 气压绝对值 |
| `_calc_short_pressure_modifier` | 短期气压突变检测 |
| `_calc_temp_rate_modifier` | 温度速率量化 |
| `_calc_weather_transition_modifier` | 雨后效应（仅 weather_only） |
| `_generate_tactical_advice` | 输出 `{depth, layer, bait, rhythm, risk, equipment_advice}` 等结构化建议 |
| `_generate_equipment_advice` | 从用户数字钓箱中匹配最优鱼竿 / 主线 / 子线 / 浮漂 / 饵料 |

## 5.9 天气预报 `forecast.py`

[`FishingForecastService`](file:///d:/diaoyu/diaoyu/domain/forecast.py) 消费 `QWeatherService.get_hourly_forecast` / `get_3day_forecast`，对每条小时 / 每日数据跑 `predict_weather_only` 评分。

| 方法 | 输出 |
|------|------|
| `calc_hourly_scores` | 24 条 `{hour, bite_index, rating, ...}` |
| `calc_best_windows` | top N 个 2h 滑动窗口（早口黄金期 / 午休 / 午后 / 傍晚） |
| `calc_daily_summary` | 日均评分 + 峰值时段 + 月相 |
| `calc_daily_score_from_weather` | 单日整体评分（用日均温） |
| `calc_3day_calendar` | 3 天日历 + `best_day` + 对比文案 |

## 5.10 外部 API 客户端

### `weather.py` — 和风天气
[`QWeatherService`](file:///d:/diaoyu/diaoyu/domain/weather.py)。所有方法 `async`：

- `get_realtime_weather(lat, lng, altitude=0)`：5 分钟内存缓存
- `get_hourly_forecast(lat, lng)`：24h 预报，30 分钟缓存
- `get_3day_forecast(lat, lng)`：3 天预报，1 小时缓存
- 内部：天气文本 → `weather_trend` 枚举映射；风向 → 8 方位；风速 km/h → m/s

### `lbs.py` — 腾讯位置
[`TencentLBSService.reverse_geocode(lat, lng) → str`](file:///d:/diaoyu/diaoyu/domain/lbs.py)，优先返回 `formatted_addresses.recommend`（如"白云湖公园"）。

### `prescription.py` — 通义千问
[`PrescriptionService(model_name="qwen-turbo", top_k=3)`](file:///d:/diaoyu/diaoyu/domain/prescription.py)。`generate_prescription(...)` 先调用 `_build_references(metrics, fish_context)` 从 [`MasterKBRetriever`](file:///d:/diaoyu/diaoyu/domain/master_kb.py) 召回 Top-3 大师秘籍，然后拼装 system + user prompt（包含 `references_block`）调 DashScope，解析 JSON；异常或缺 Key 时返回 `_fallback_prescription`（含 `references: []`）。`max_tokens=1500` 以容纳 RAG 参考输出。

### `prompts.py` — Prompt 模板
[`prompts.py`](file:///d:/diaoyu/diaoyu/domain/prompts.py)：`SYSTEM_PROMPT_FISHING_EXPERT` 角色设定（30 年华南老钓手），额外约束“提供【参考大师秘籍】时优先借鉴”；`build_user_prompt(..., references_block="")` 拼装鱼种 / 钓法 / 物理指标 / 物理标签 / 主观症状 / 装备库 / RAG 参考块。要求 LLM 严格输出 JSON `{diagnosis, prescriptions[], references[], confidence_note}`。

### `master_kb.py` — 大师知识库检索器（RAG）
[`MasterKBRetriever`](file:///d:/diaoyu/diaoyu/domain/master_kb.py) 进程级单例懒加载 [`data/master_kb.jsonl`](file:///d:/diaoyu/diaoyu/data/master_kb.jsonl)（322 条）。`search(target_fish, season, t_water, pressure_state, top_k=3)` 按鱼种+5 / 季节+3 / 温区+3 / 气压+2 / 完整度加权评分，阈值 `score >= 3`；`format_references_for_prompt` 输出为拼接到 user prompt 的参考文本块。详见 [10-大师知识库RAG](./10-大师知识库RAG.md)。

### `poster.py` — 战报海报
[`PosterGenerator.generate_poster_data(session)`](file:///d:/diaoyu/diaoyu/domain/poster.py) 输入 `{duration_min, catch_level, delta_p}`，输出标题、背景色、文字行、击败百分位。
