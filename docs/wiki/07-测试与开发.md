## 1. 测试框架与配置

| 项目 | 值 |
|---|---|
| 测试框架 | `pytest` |
| 测试目录 | `tests/` |
| 配置文件 | [pytest.ini](file:///d:/diaoyu/diaoyu/pytest.ini) |
| 命名约定 | `test_*.py` / `Test*` 类 / `test_*` 函数 |

[pytest.ini](file:///d:/diaoyu/diaoyu/pytest.ini#L1-L6) 内容：

```ini
[pytest]
testpaths = tests
python_files = test_*.py
python_classes = Test*
python_functions = test_*
```

运行：

```bash
# 全部测试
pytest -v

# 单文件
pytest tests/test_domain.py -v

# 单个用例
pytest tests/test_domain.py::TestAnalyzers::test_water_temp_score -v

# 显示覆盖率（需先 pip install pytest-cov）
pytest --cov=domain --cov=infrastructure --cov-report=term-missing
```

## 3. 测试编写约定

- **不依赖外部网络**：天气/LBS/LLM 调用一律 mock 或在测试中跳过；纯算法测试只用值对象。
- **断言数值用范围**：`bite_index` 等浮点结果使用 `assert 60 <= score <= 80` 而非精确等值。
- **置信度单调性**：`TestProgressiveReportE2E` 的 `test_confidence_increases` 是回归基准，新增评分项务必保证不破坏。
- **共享 fixture**：装备测试中的 `api_normal`/`api_windy`/`sample_inventory` 是公共 fixture，复用同一仓库结构。

## 4. CLI 演示：[main.py](file:///d:/diaoyu/diaoyu/main.py)

`main.py` 是离线算法演示器，**不依赖 HTTP / 数据库 / 外部 API**，便于本地调参。

```bash
# 默认：鲫鱼 + 时序模式（30 分钟）
python main.py

# 指定鱼种
python main.py --fish 鲤鱼

# 单帧快照模式（V1 兼容）
python main.py --mode legacy

# 模拟 60 分钟时序
python main.py --mode series --duration 60
```

参数定义见 [argparse 段](file:///d:/diaoyu/diaoyu/main.py#L50-L71)：

| 参数 | 默认 | 说明 |
|---|---|---|
| `--fish` | `鲫鱼` | 候选取自 `FISH_PROFILES.keys()` |
| `--mode` | `series` | `legacy` 单帧 / `series` 时序 |
| `--duration` | `30` | 仅 `series` 模式有效，单位分钟 |

时序数据由 [_build_mock_series](file:///d:/diaoyu/diaoyu/main.py#L16-L46) 构造：水底 18→19.5℃ 缓慢上升、气压 1008→1009.5 hPa 回升、表底温差 ~2℃，每 5 秒一帧。

时序模式会依次输出 4 段报告（[_run_series_mode](file:///d:/diaoyu/diaoyu/main.py#L114-L161)）：

1. **完整报告**（`full` 阶段）—— 全部数据
2. **instant**（最新一帧）
3. **brief**（最近 5 分钟）
4. **standard**（最近 10 分钟）

可直观比较置信度从 ~30 → ~95 的演进。

## 6. 本地开发常用流程

```bash
# 1. 创建并激活虚拟环境
python -m venv venv
venv\Scripts\activate          # Windows
source venv/bin/activate       # Linux/macOS

# 2. 安装依赖
pip install -r requirements.txt

# 3. 配置环境变量（最少需要 DATABASE_URL，其余可选）
copy .env.example .env         # 若有
notepad .env

# 4. 初始化 / 迁移数据库（若已有旧数据）
python migrate_v2.py

# 5. 启动开发服务器（uvicorn 自带热重载）
python server.py               # 默认 0.0.0.0:8000，--reload

# 6. 浏览器查看交互式文档
# http://127.0.0.1:8000/docs    （Swagger UI）
# http://127.0.0.1:8000/redoc   （ReDoc）

# 7. 跑全量单测确保无回归
pytest -v
```

## 7. 调试技巧

- **打开评分中间值**：在 [domain/services.py](file:///d:/diaoyu/diaoyu/domain/services.py) 的融合段添加 `print` / `logger.debug`，再用 `python main.py` 复现。
- **构造异常时序**：直接修改 [_build_mock_series](file:///d:/diaoyu/diaoyu/main.py#L16-L46)，例如让 `p_local` 在末段急跌 -3.5 hPa，验证一票否决是否触发。
- **隔离单个 Analyzer**：在 `tests/test_domain.py::TestAnalyzers` 内复制一段、改输入即可定位某个修正项的边界。
- **接口侧调试**：用 `/docs` 的 Try it out 直接发请求，比 Postman 更省事；批量场景用 [test_api.py](file:///d:/diaoyu/diaoyu/test_api.py)。
