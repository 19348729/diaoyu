# DS18B20 双探头测试

## 测试目的
测试在 ESP32 的 GPIO15 引脚上连接两个 DS18B20 温度探头的功能。

## 硬件接线

### 接线方式
```
ESP32 GPIO15 ──┬── DS18B20 #1 DATA
               └── DS18B20 #2 DATA
               
ESP32 3.3V ────┬── DS18B20 #1 VCC
               └── DS18B20 #2 VCC
               
ESP32 GND ─────┬── DS18B20 #1 GND
               └── DS18B20 #2 GND
```

### 上拉电阻
**重要**: GPIO15 必须通过 4.7kΩ 上拉电阻连接到 3.3V

```
3.3V ──[4.7kΩ]── GPIO15 ── DS18B20 DATA 引脚
```

## 使用方法

### 1. 上传文件到 ESP32
使用 ampy 或 mpfshell 将 `test_dual_probe.py` 上传到 ESP32：

```bash
# 使用 ampy
ampy --port /dev/ttyUSB0 put test_dual_probe.py

# 或使用 mpfshell
mpfshell -c "put test_dual_probe.py"
```

### 2. 运行测试
在 ESP32 的 REPL 中运行：

```python
import test_dual_probe
test_dual_probe.main()
```

或者直接执行：

```python
exec(open('test_dual_probe.py').read())
```

### 3. 查看输出
测试脚本会：
1. 扫描并显示检测到的 DS18B20 探头的 ROM 地址
2. 循环读取并打印每个探头的温度值
3. 显示时间戳和 ROM 地址信息

## 故障排查

### 未检测到探头
如果显示 "未检测到任何 DS18B20 探头"，请检查：
1. 探头是否正确连接到 GPIO15
2. 是否连接了 4.7kΩ 上拉电阻
3. VCC 和 GND 是否正确连接
4. 探头是否损坏

### 温度值显示 85.0°C
这是 DS18B20 上电后的默认值，等待几秒后会显示正常温度。

### 温度值显示 -127.0°C
表示通信失败，可能是：
1. 上拉电阻未连接或阻值不对
2. 接线松动
3. 单总线时序问题

## 停止测试
按 `Ctrl+C` 可以手动停止测试。
