# AI 钓鱼智能系统 V2.0 🐟

本项目是一套完整的 **IoT + AI 钓鱼战术专家系统**。经过 V2.0 的全新升级，系统从“密集的实时监控仪表盘”进化为“极简的三次握手流式体验”，并深度集成了大语言模型（通义千问）作为分析大脑，结合硬件底层的极端省电优化，为钓友提供全方位的智能护航。

## 🌟 V2.0 核心特性

1. **极端续航保护 (ESP32)**
   - 抛弃了高功耗的常驻唤醒，重构为主循环睡眠策略。
   - 使用 `keepalive_sleep` 脉冲技术，完美兼顾“充电宝小电流保护不关机”与“极低功耗运作”。
   - 引入 Flash `RingBuffer`，意外断电不丢数据。
2. **REQ-ACK 批量快闪同步 (BLE)**
   - 全新的通信协议，设备重连后 1 秒内可实现百条水文数据的全量 Dump (`CMD_BULK_DUMP`)。
   - 彻底解放手机，作钓期间手机可随时锁屏放回口袋。
3. **AI 鱼情救场 (DashScope 接入)**
   - 当作钓遇到停口、杂鱼闹窝等异常时，提交主观症状，后端物理引擎会结合 2 小时内的气压、水温变率，打上特征标签。
   - 通过通义千问 (Qwen) 扮演的“30年老钓手”生成包含诊断和具体操作建议的 JSON 处方卡片。
4. **极简三屏工作流 (微信小程序)**
   - 告别繁杂的 5 个 TabBar 仪表盘，改为线性动线：**出钓配置 (Setup)** -> **AI 救场 (Rescue)** -> **战报海报 (Report)**。

## 🔗 V2.0 业务流：三次精确握手

### 1️⃣ 第一次握手：开局配置 (Setup)
- **用户行为**：到达钓点后，在小程序中选择**目标鱼种**、**钓法**和**饵料**，点击“开始作钓”。
- **系统行为**：小程序通过 BLE 连接 ESP32，下发时间同步对表。保存作钓 Context。
- **提示**：“设备已就绪，手机可以放回口袋了”。

### 2️⃣ 第二次握手：AI 鱼情救场 (Rescue)
- **用户行为**：遇到不咬钩、走水严重等突发状况，掏出手机进入“AI 救场”页，勾选水面症状（如：*看到鱼跳但不吃饵*）。
- **系统行为**：
  1. 小程序发送 `CMD_BULK_DUMP`，ESP32 在 1 秒内将离线期间收集的几十条水温、气压数据全部推给手机。
  2. 手机连同用户症状转发给后台 `/api/v2/rescue`。
  3. 后台 `engine.py` 计算出物理变率（如 *气压近两小时剧降2hPa*，*存在强温跃层*）。
  4. 后台 `prescription.py` 调用大语言模型，结合物理变率与主观症状生成 **AI 战术处方**。
- **产出**：结构化处方（包含原理解释与操作指令，例如：*推漂30cm钓离底*）。

### 3️⃣ 第三次握手：收竿战报 (Report)
- **用户行为**：结束作钓，选择今天的战绩表现（坚强空军 / 惨淡 / 稳赚 / 爆护），点击生成战报。
- **系统行为**：主动断开与 ESP32 的连接让其深度休眠，调用 `/api/v2/poster` 结合当日的综合气压趋势和分数，生成可供发朋友圈的成就海报。

## 🔌 硬件参数与 BLE 指令码 (V2.0)

硬件采用 ESP32 采集水下温度、水面温度、气压，使用 BLE GATT。新增了 Fast Dump 相关协议：

| CMD | 方向 | 名称 | 描述 |
|---|---|---|---|
| `0x01` | 小程序 → ESP32 | 对表指令 | 同步 Unix 时间戳 |
| `0x02` | ESP32 → 小程序 | 实时数据帧 | 可选，配合 V1 仪表盘使用 |
| `0x03` | ESP32 → 小程序 | 历史数据帧 | 批量传输缓冲区记录 |
| `0x04` | 小程序 → ESP32 | 同步确认 | 滑动发送游标 |
| `0x08` | 小程序 → ESP32 | **快闪拉取** | V2 专属，全量请求历史 |
| `0x09` | ESP32 → 小程序 | **快闪结束** | V2 专属，标记 Dump 完成 |
| `0x0A` | 小程序 → ESP32 | **切换实时** | 恢复 Notify 实时推送模式 |

> V2 协议下，收到 `0x08` 后，ESP32 会快速连发 `0x03`，无须等待 `0x04` 确认，直至发完再发送 `0x09`，由小程序统一 `0x04` ACK，极大提高蓝牙同步效率。

## 🚀 快速开始

### 1. 服务端运行 (FastAPI)
必须配置阿里云通义千问 API 密钥方可使用 AI 处方功能：
```bash
# 环境变量配置
export DASHSCOPE_API_KEY="your-qwen-key"

# 安装依赖
pip install -r requirements.txt

# 启动服务
python server.py
```

### 2. ESP32 固件烧录
使用 Thonny 或 `ampy` 将 `esp32/` 目录的内容上传至 ESP32 文件系统根目录。
注意：V2 版本默认开启了文件持久化，会在根目录自动创建 `/ring.bin` 存储传感器数据，请确保设备有约 100KB 的 Flash 剩余空间。

### 3. 小程序开发
使用微信开发者工具打开 `miniprogram/` 目录。
请在 `app.js` 中将全局配置 `apiBaseUrl` 修改为你部署的服务器地址。
（V1.x 的页面如 `pages/index` 和 `pages/decision` 等已放入 `pages/settings` 内备用）。
